# Laravel – Travaux pratiques

Ce dépôt regroupe mes différents travaux pratiques réalisés autour du framework **Laravel** dans le cadre de mon apprentissage du développement web.

Il me sert d'archive personnelle afin de conserver mes exercices, mes essais et les différentes étapes de ma progression.

## Contenu du dépôt

Les travaux sont organisés par dossiers, correspondant aux différents TP et à leurs variantes.

| Dossier | Contenu |
|---|---|
| `ds1` | Travaux et exercices |
| `tp1` | TP 1 |
| `tp1bis` | Variante du TP 1 |
| `tp1ter` | Variante du TP 1 |
| `tp2` | TP 2 |
| `tp2bis` | Variante du TP 2 |
| `tp2ter` | Variante du TP 2 |

## Objectif

Ce dépôt a une vocation essentiellement pédagogique et personnelle :

- Archiver mes travaux pratiques.
- Conserver une trace de mon apprentissage de Laravel.
- Garder un historique de mes exercices et de leurs évolutions.
- Rendre mon travail consultable.
